# يَزِيد 🌙

يَزِيد رفيق يومي للعبادة: العدّ التنازلي، ومواقيت الصلاة، والورد اليومي، والتنبيهات، ومكتبة للريلز والمنشورات والأحاديث.

## ملفات الموقع

- `index.html` هي الصفحة الرئيسية للموقع، وتحمّل `styles.css` و`script.js` وأيقونة التبويب `favicon.svg` من المجلد نفسه.
- `adhkar.html` و`adhkar.js` تعرضان أذكار الصباح والمساء في صفحة مستقلة، وتدعمان فتح الفترة المختارة مباشرةً عبر `?period=morning` أو `?period=evening`. ترتيب الأذكار ثابت في ملفات الموقع، ويُحدّث عند اعتماد ترتيب جديد؛ أما عدّ الترديد فيُحفظ على الجهاز لكل ذكر ولكل يوم. تتضمن الأذكار مصادر قابلة للفتح وتعرض عدد التكرار.
- `styles.css` يحتوي على تنسيقات الصفحة.
- `script.js` يحتوي على وظائف الصفحة.
- `reels.html` و`posts.html` و`hadith.html` صفحات المحتوى، و`quran.html` صفحة المصحف ضمن المكتبة.
- `radio.html` صفحة الإذاعات ومشغل المحطات، مع `radio.js` و`radio-page.css` وقائمة القراء في `radio-reciter-data.js`.
- `radio-player.html` و`radio-player.js` و`radio-player.css` نافذة المشغل الصوتي المستقلة التي تستمر أثناء تصفح صفحات الموقع.
- `scroll-navigation.js` يضيف زري الصعود والهبوط لجميع صفحات الموقع.
- `content-pages.css` و`content-pages.js` تنسيقات ووظائف صفحات المحتوى.
- `quran-reader.js` وظائف تصفح صفحات المصحف واختيار السور في `quran.html`.
- `content-data.js` يحتوي على محتوى الريلز والمنشورات والأحاديث الذي يظهر لجميع الزوار. إضافة ملف إلى مجلد `videos` وحدها لا تنشره تلقائيًا؛ يجب تسجيله كذلك في مصفوفة الريلز بهذا الملف.
- ضع ملفات الفيديو المنشورة في مجلد `videos` بجانب ملفات الموقع.

احتفظ بهذه الملفات معًا في المجلد نفسه. يحتاج الطقس والبحث عن المدن والقرآن إلى اتصال بالإنترنت. يطلب الموقع إذن المتصفح لتحديد موقعك تلقائيًا؛ يتطلب ذلك عادةً HTTPS أو localhost. إذا لم تسمح بالإذن، يمكنك البحث عن المدينة يدويًا.

يطلب الموقع إذن المتصفح لتحديد موقعك تلقائيًا، ثم يرسل الإحداثيات إلى خدمتي Open-Meteo وBigDataCloud لتحديث مواقيت الصلاة والطقس وعرض اسم المدينة؛ يلزم HTTPS أو localhost، ويمكن اختيار مدينة يدويًا عند تعذّر ذلك. تعمل تذكيرات الصلاة والإفطار والأذكار وآية اليوم أثناء بقاء الصفحة مفتوحة، ويمكن تشغيل نغمة قصيرة معها. تظهر التنبيهات العائمة وإشعارات النظام لمدة ١٠ ثوانٍ، بينما قد يطبق نظام التشغيل إعدادات إضافية على إشعاراته. وصول الإشعارات عند إغلاق الصفحة يحتاج إعدادًا إضافيًا.

تعرض قائمة **التقويم** في شريط التنقل خيارين: تقويم الشهر الحالي مع تمييز تاريخ اليوم، وتقويم رمضان ١٤٤٨ هـ. يفتح رابط **الإذاعة** صفحة مستقلة تتضمن بث مصر ومكة وقصص الأنبياء، إضافة إلى مصحف كامل منفصل لكل قارئ من القراء المدرجين، ومنهم سعود الشريم. بطاقات القراء مختصرة وبها اختيار السورة وزر تشغيل، ويستخدم الجميع مشغلًا واحدًا لمنع تشغيل أكثر من قارئ في الوقت نفسه. يمكن فتح البث الصوتي في نافذة مشغل مستقلة من زر **فتح المشغل العائم**؛ ابدأ البث من النافذة قبل الانتقال إلى صفحة أخرى. يسمح المتصفح بفتح هذه النافذة نتيجة ضغط المستخدم فقط، وقد يتطلب السماح بالنوافذ المنبثقة. تفتح قناة السنة النبوية مشغل الهيئة الرسمي داخل الصفحة مع رابط بديل لموقعها. قسم التفريغ التلقائي مخفي بناءً على طلب المستخدم، بينما أبقينا كوده محفوظًا للعودة إليه مستقبلًا؛ لا يوجد تفريغ نشط الآن. يوجد المصحف الشريف كصفحة مستقلة ضمن مجموعة **المكتبة** بجانب الريلز والمنشورات والأحاديث، بينما يبقى الورد اليومي في الصفحة الرئيسية. على الشاشات الصغيرة، يبدأ شريط التنقل مختصرًا ويمكن توسيعه بزر القائمة. يوجد زر صغير لإنشاء صورة العدّ التنازلي داخل بطاقة العدّ التنازلي، ويعرض العداد الأيام المتبقية لرمضان. تتغير الآية الظاهرة في كل صورة جديدة. تتيح أزرار الصور اختيار نمط الصورة ثم معاينتها وتنزيلها أو مشاركتها من قائمة المشاركة التي يدعمها الجهاز؛ تُنشأ الصور بتنسيق رأسي مناسب للهاتف، وتتوفّر أزرار صور منفردة لبطاقات «زادك اليومي» وورد القرآن. عند عدم دعم مشاركة الملفات، يمكن تنزيل الصورة ثم نشرها يدويًا. إعدادات التنبيهات اليومية ظاهرة دائمًا وبداخلها زر لتفعيل الإشعارات أو إيقافها. اختيار المناسبة من الأزرار يدوي؛ لا يتغير العدّ التنازلي تلقائيًا أثناء بقاء الصفحة مفتوحة.

يتضمن شريط التنقل زر تغيير المظهر، وتفتح روابطه في الصفحة نفسها. يمكن إنشاء صور العدّ التنازلي والمحتوى بمقاس رأسي للقصص أو مربع للمنشورات. تُدار مكتبة الريلز والمنشورات والأحاديث كملفات ثابتة ضمن الموقع، لذلك لا تحتاج إلى إعداد Supabase أو مفاتيح API.

## إضافة محتوى جديد

الموقع الثابت لا يستطيع رفع ملف من المتصفح إلى ملفات الاستضافة. نشر المحتوى يتم بتحديث ملفات الموقع؛ لذلك تحكّم بمن يستطيع النشر عبر صلاحيات المستودع والاستضافة، ولا تمنحها إلا للمالك. لإضافة ريل:

1. ضع الفيديو داخل مجلد `videos` بجانب صفحات الموقع؛ يفضّل MP4 بترميز H.264 وحجم مناسب لاستضافتك.
2. أضف عنصرًا في مصفوفة `reels` داخل `content-data.js`. اكتب مسار الفيديو نسبةً إلى مجلد الموقع:

   ```js
   window.YAZEED_CONTENT = {
     reels: [
       { title: "عنوان الفيديو", url: "videos/my-reel.mp4", description: "وصف الفيديو" }
     ],
     posts: [],
     hadith: []
   };
   ```

3. أضف المنشورات إلى `posts` (`title`, `text`, و`image` اختياري)، والأحاديث إلى `hadith` (`text`, `source`, و`explanation` اختياري). راجع مصدر الحديث وتخريجه قبل النشر.
4. ارفع `content-data.js` ومجلد `videos` مع بقية ملفات الموقع إلى الاستضافة. سيظهر المحتوى لجميع الزوار بعد تحديث الموقع. الملفات السبعة الموجودة حاليًا في `videos` ولا تظهر كبطاقات هي نسخ مطابقة لمقاطع موجودة؛ أي فيديو جديد يجب تسجيله في `content-data.js` قبل نشره.

أُضيف الريل `إن شئتِ صبرتِ` إلى الموقع في `videos/in_shi2ti_sabarti.mp4` وربطته ببطاقة صفحة الريلز. لإضافة فيديو آخر، أرفقه هنا وسأجهّز ملفه وأحدّث `content-data.js`. لا أستطيع النشر مباشرةً على حساب الاستضافة من دون صلاحية تكامل/نشر؛ ارفع الملف المحدّث والمجلد `videos` إلى استضافتك.

جهّزت أيقونات التواصل لإضافة الروابط لاحقًا عبر سمة `data-social-url` لكل أيقونة في `index.html`. تعرض صفحة `quran.html` قارئ المصحف كاملًا، صفحة واحدة في كل مرة، مع التنقل بين الصفحات واختيار صفحة أو سورة. يحتاج النص القرآني إلى اتصال بالإنترنت؛ يجلب القارئ النص وقائمة السور من AlQuran Cloud.

## إعداد التفريغ المباشر

التفريغ التلقائي مؤجل ومخفي من واجهة صفحة الإذاعة. احتفظنا بملفاته داخل `transcription-server/` واتصال WebSocket في `radio.js` للعودة إليها مستقبلًا؛ لا يلزم تشغيلها الآن.

## النشر على GitHub Pages

1. ارفع ملفات الموقع المعتادة، بما فيها `radio-reciter-data.js` و`scroll-navigation.js`، ومجلد `videos` إلى GitHub Pages كما هو موضح أدناه. لا حاجة إلى رفع `transcription-server` أو تشغيله الآن.
2. من **Settings → Pages**، اختر Branch `main` والمجلد `/ (root)` ثم Save.
3. افتح `https://USERNAME.github.io/REPO/`، ثم استخدم صفحات `quran.html` و`radio.html` و`reels.html` و`posts.html` و`hadith.html` من المكتبة وشريط التنقل.

يفتح GitHub Pages ملف `index.html` تلقائيًا عند زيارة رابط المستودع من دون اسم ملف.

## تعديل التواريخ

التواريخ المتوقعة موجودة في مصفوفة `EVENTS` داخل `script.js`. عدّلها إذا اختلف الإعلان الرسمي.

## تجربة وضع الإفطار

أضف `#iftar` إلى نهاية رابط الصفحة، مثل `index.html#iftar`.
